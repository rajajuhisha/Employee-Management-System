# Employee Management System

## Overview

Employee Management System is a full-stack web application developed using ASP.NET Core Web API, HTML, CSS, and JavaScript.

The application allows users to add, update, delete, search, and view employee records through an interactive dashboard.

## Features

- Add Employee
- Update Employee
- Delete Employee
- Get Employees
- Search Employees
- Total Employees Count
- Department Count
- Total Salary Summary

## Technologies Used

### Backend
- ASP.NET Core Web API
- C#
- REST API

### Frontend
- HTML
- CSS
- JavaScript

### Tools
- Visual Studio
- Swagger
- GitHub

## API Operations

- GET Employee
- GET Employee By Id
- POST Employee
- PUT Employee
- DELETE Employee

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Run the ASP.NET Core Web API.
4. Open the frontend application.
5. Start managing employee records.

- JavaScript Fetch API
